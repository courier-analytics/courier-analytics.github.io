Доработка смены оценивается по времени последней успешно завершённой доставки: не раньше чем за 30 минут до планового окончания. Учитываются курьеры, подтвердившие выход доставками.

Обучение за 15–17.10 — предварительные показатели: возможны повторно обученные курьеры. За 17.10 выход по плану уточнён по более поздней выгрузке доставок: 30 из 35 плановых смен (85,71%) вместо ранее опубликованных 27 из 35 (77,14%). Для оценки доработки смены: 15.10 — 27 из 41 подтверждённых смен, 16.10 — 20 из 40, 17.10 — 16 из 30 (по поздней выгрузке заказов), 18.10 — 25 из 39; строка графика с несколькими ФИО считается одной сменой. За 18.10 выход по плану определяется наличием доставок, независимо от статуса в графике: 39 из 45 плановых смен; опоздания — только среди подтверждённых доставками смен со статусом «опоздал»: 3 из 39. Работа вне плана — по уникальным курьерам с заказами (20 из 65), доработка — по последней успешной доставке с допуском 30 минут (25 из 39 смен). Двое отдельно указанных курьеров исключены из расчётов плана и внеплана. Данные за 18.10 предварительные; отсутствующие показатели не заполнялись. За 19.10 предварительные значения по выгрузке до 16:29: выход по плану 38 из 45 (84,44%), опоздания 16 из 38 (42,11%) по первой успешной доставке позже 30 минут от начала смены, внеплан 16 из 55 (29,09%); опросники 61 из 104 (58,65%). По полной выгрузке заказов за 19.10 доработали смену 26 из 41 курьера с подтверждённым выходом (63,41%); в графике 45 уникальных плановых смен, два курьера с пометкой «не слот» и повторная запись одного курьера исключены, четыре смены без успешных доставок. Доработка оценена по последней успешной доставке не ранее 30 минут до конца плановой смены. Остальные отсутствующие показатели за 19.10 пока не предоставлены.

20.10 — предварительные показатели по выгрузке успешных доставок до 14:14: 43 из 53 плановых смен подтверждены (81,13%), опоздания 20 из 43 (46,51%) при допуске 30 минут, вне плана 18 из 61 уникального курьера (29,51%). Данные требуют уточнения после окончания вечерних смен. Заполнение слотов относительно ориентира по графику: 52 из 62 дневных слотов заполнены (83,87%); 10 дневных слотов не заполнены. Смены с началом в 20:00 и позже, выходные и строки без времени исключены.
